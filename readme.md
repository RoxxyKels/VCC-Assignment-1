
Project Overview
VCC assignment one 
 The project serves as a demonstration of basic version control concepts, including repository creation, file management, commits, and remote repository management.

Project Purpose

The purpose of this project is to develop practical experience using Git to track changes to files and GitHub to host and manage a remote repository.

This project demonstrates how developers can organize project files, maintain a history of changes, and collaborate using version control tools.

Project Contents

The repository contains the following files:

README.md: Provides an overview of the project, its purpose, and its contents.
index.html: Contains sample HTML for the Cloud Nine Spa homepage.
about.txt: Provides background information about the fictional spa.
services.txt: Lists example spa and wellness services.
contact.txt: Contains sample contact information for the business.
notes.txt: Contains project notes and information about version control.
Tools and Technologies

The following tools are used in this project:

Git: Tracks file changes and maintains the project's commit history.
GitHub: Hosts the remote repository.
Visual Studio Code: Provides the development environment for creating and editing files.
macOS Terminal: Used to execute Git commands.
Markdown: Used to format this README document.
Version Control Workflow

Git is used to manage changes to the project files through the following workflow:

Create or modify project files.
Stage the changes using git add.
Record the changes using git commit.
Review the commit history using git log --oneline.
Push local commits to GitHub using git push.
Verify the remote repository configuration using git remote -v.

Each commit includes a descriptive message explaining the changes made.

Learning Objectives

This project demonstrates the ability to:

Create a public GitHub repository.
Clone a remote repository to a local workstation.
Create and organize project files.
Stage and commit changes using Git.
Write clear and descriptive commit messages.
Push commits from a local repository to GitHub.
Review project history and verify remote repository settings.
Project Status

This repository is an educational project created to practise fundamental Git and GitHub operations. Cloud Nine Spa is a fictional business and the project is not intended to represent a fully operational commercial website.

Conclusion

This project provides practical experience with version control and demonstrates how Git and GitHub can be used to manage project files, record changes, and maintain a history of development.
